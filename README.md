# ⚔️ Witcher 3 Azerbaijani Strings Translation

This repository contains **Azerbaijani translation files** for *The Witcher 3: Wild Hunt* string resources.

It is part of an ongoing localization effort to make the game more accessible for Azerbaijani players.

---

## 📦 Installation

### 📍 File Location

Place the string files into one of the following directories:

### 🟢 If you have NO DLC installed:

\SteamLibrary\steamapps\common\The Witcher 3\content\

### 🔵 If DLCs are installed:

\SteamLibrary\steamapps\common\The Witcher 3\content\content0
